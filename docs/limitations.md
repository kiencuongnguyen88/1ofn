# Limitations

`1ofN` is a reasoning method, not an evidence generator.

## 1. Bad evidence still produces bad decisions

The method can expose weak claims, but it cannot turn missing facts into true facts. For law, medicine, finance, engineering measurement, safety, or other specialist domains, obtain the right evidence first.

## 2. Framing bias can survive the method

If the desired outcome is wrong, the entire run can optimise the wrong problem. FRAME is a real stage, not decorative setup.

## 3. Expansion can become idea inflation

Adding an option only helps when it changes the decision space. Candidates that merely rephrase another option should MERGE rather than count as creativity.

## 4. Challenge can become performative skepticism

Contrary evidence must be relevant. Inventing objections merely to sound balanced reduces signal.

## 5. Verdicts are not moral labels

`REMOVE` does not mean “bad.” It means the option no longer has distinct material value in the current decision.

`PARK` does not mean weak. It means timing or evidence does not justify commitment now.

## 6. 1ofN does not promise one winner

The name describes **one among N** as a choice problem. A valid result may still be MERGE, PARK, or BLOCKED.

If two options should become one path, or if the evidence is insufficient, forcing a winner violates the method.

## 7. Scores can create false precision

1ofN does not require weighted scoring. Use numbers only when the measurements and weights are defensible.

## 8. Some decisions should remain blocked

If missing evidence is material and cannot be safely inferred, `BLOCKED` is the correct result.

## 9. Human judgment still matters

The method makes reasoning inspectable; it does not transfer responsibility for the decision to a model or framework.

## 10. Not every decision deserves 1ofN

For obvious, reversible, low-cost choices, use a simpler process and act.
