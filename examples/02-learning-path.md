# Worked Case 2 — Choose How to Learn a New Technical Skill

## Situation

A learner wants to become practically competent in a new technical skill within three months.

Known options:

1. complete a structured course from start to finish;
2. learn entirely through a personal project;
3. use tutorials only when blocked.

Desired outcome: build usable skill, not merely finish content.

Constraints:

- limited weekly time;
- the learner needs enough fundamentals to avoid repeated confusion;
- motivation drops when learning stays abstract for too long.

## 1. FRAME

The decision is not “course or project?”

It is:

> What learning structure creates enough foundation to make progress while forcing frequent real application?

## 2. EXPAND

Add:

4. a hybrid: short foundation module → project → targeted lessons when blocked;
5. cohort/live class.

## 3. CHALLENGE

| Candidate | Support | Contrary evidence / failure mode |
|---|---|---|
| Full course | coherent sequence; fewer knowledge gaps | completion can become the goal; application arrives late |
| Project-only | high relevance; real feedback | foundational gaps can create noisy trial-and-error |
| Tutorial-on-block | efficient local repair | no initial map; may produce fragmented knowledge |
| Hybrid loop | combines map + practice + targeted repair | requires discipline to avoid returning to passive course completion |
| Cohort | social accountability | schedule and pacing may not fit the learner |

## 4. DISTILL

- Full course → **MERGE**. Keep a small foundation segment, not the entire course-first strategy.
- Project-only → **MERGE**. Keep the real project as the main practice surface.
- Tutorial-on-block → **MERGE**. Use as targeted repair.
- Hybrid loop → **KEEP**.
- Cohort → **PARK**. Useful only if accountability becomes the dominant problem.

## 5. DECIDE

**Selected path:** short foundation → real project → targeted repair loop.

Why it survives:

- protects against foundational confusion;
- keeps reality contact high;
- limits passive learning;
- allows the learning plan to adapt to actual gaps.

### Reversal condition

If the learner repeatedly stops working without external accountability, reopen the cohort option.

### Next action

Choose one small project and define the minimum foundation needed to start it within the first week.
